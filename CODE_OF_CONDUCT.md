# Code of conduct

We want RevKlik's issue tracker, pull requests and discussions to be a place where people can do
good work without harassment.

## Expected behavior

- Be respectful and assume good faith. Disagree with the idea, not the person.
- Give and accept feedback on code and design constructively.
- Keep discussion on topic and use inclusive language.

## Unacceptable behavior

- Harassment, discrimination, insults, threats, or sexualized language and imagery.
- Publishing someone's private information without permission.
- Sustained disruption of discussions, or other conduct that would reasonably be considered
  inappropriate in a professional setting.

## Enforcement

Maintainers may edit, hide or remove comments, issues and pull requests that violate this code,
and may restrict participation. Report concerns to **security@revklik.com**; reports are handled
privately.

This code of conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
