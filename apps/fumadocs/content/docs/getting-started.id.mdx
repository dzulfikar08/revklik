## 1. Buat akun

Daftar di [app.revklik.com/register](https://app.revklik.com/register) dengan
email dan kata sandi, atau lanjutkan dengan Google. Setiap akun baru langsung
mendapat **uji coba Growth 7 hari tanpa kartu**. Dashboard tersedia dalam
Bahasa Indonesia dan bahasa Inggris (ganti lewat tombol ID/EN).

## 2. Tambahkan situs Anda

Di halaman **Situs**, klik **Tambah situs** (di dasbor sebuah situs, buka
pemilih situs di bilah atas lalu pilih **Manage sites**). Isi:

- **Nama situs**: nama apa saja yang membantu Anda mengenali situs, misalnya `Blog saya`.
- **Domain situs**: misalnya `example.com`. Anda boleh menempelkan URL lengkap:
  skema, path, dan garis miring di akhir akan dibuang, dan domain diubah ke
  huruf kecil. Setiap domain hanya bisa ditambahkan sekali.

Klik **Tambah situs** dan snippet pelacakan langsung terbuka.

## 3. Pasang snippet pelacakan [#install-the-tracking-snippet]

Snippet-nya satu tag script. Ganti `YOUR_SITE_ID` dengan ID situs Anda:

```html
<script defer data-site-id="YOUR_SITE_ID" src="https://app.revklik.com/klikapa.js"></script>
```

Jendela **Snippet pelacakan** menampilkan tag ini dengan ID situs yang sudah
terisi, jadi salin dari sana dengan **Salin snippet**. Untuk membukanya lagi,
klik **Snippet** pada baris situs di **Manage sites**, atau **Pasang snippet**
pada kartu situs yang bertanda _Belum terpasang_.

Pasang tag ini satu kali di setiap halaman yang ingin Anda ukur. Tracker
mengikuti aplikasi satu halaman (SPA) dengan sendirinya: perpindahan rute
dihitung sebagai pageview.

Buat tag **Custom HTML** yang aktif di **All Pages**. Tag Manager menjalankan

```html
<script>

		s.defer = true;
		s.src = "https://app.revklik.com/klikapa.js";
```

### Content Security Policy

Jika situs Anda mengirim header `Content-Security-Policy`, izinkan RevKlik
memuat script dan menerima event:

```
script-src https://app.revklik.com;
connect-src https://app.revklik.com;
```

Tambahkan origin ini ke direktif yang sudah Anda pakai, jangan menggantinya.
Pada instalasi self-hosted, gunakan origin yang menyajikan `klikapa.js`.

### Tidak ada data? Periksa ini [#no-data-check]

- **Ad blocker atau ekstensi privasi.** Sebagian memblokir script analitik.
  Buka situs di jendela pribadi dengan ekstensi dimatikan.
- **Content Security Policy.** Konsol browser menampilkan script atau request
  yang diblokir bila CSP penyebabnya. Izinkan `app.revklik.com` seperti di atas.
- **Site ID salah.** Tracker tidak melakukan apa-apa tanpa `data-site-id`, dan
  data masuk ke situs pemilik ID tersebut. Bandingkan ID di sumber halaman
  Anda dengan ID di jendela snippet.
- **Domain tidak cocok.** Snippet yang disalin dari situs lain mengirim
  datanya ke situs itu. Setiap domain di **Manage sites** punya snippet sendiri.
- **Pengembangan lokal.** Tracker mengabaikan `localhost` dan alamat lokal
  lainnya. Tambahkan `data-track-localhost="true"` pada tag untuk menguji di sana.
- **Gerbang persetujuan.** Bila `data-consent="required"` dipasang, tidak ada
  yang disimpan atau dikirim sampai halaman Anda memanggil
  `klikapa.consent(true)`. Lihat [persetujuan](#consent) di bawah.
- **Global Privacy Control atau Do Not Track.** Tracker menghormati keduanya:
  pengunjung yang browsernya mengirim salah satu sinyal itu tidak dicatat.
  Browser Anda sendiri mungkin mengaktifkannya.

Masih buntu? [FAQ](/id/faq) menjelaskan apa yang dikumpulkan script dan
bagaimana retensi data bekerja.

## 4. Lacak lebih dari pageview

Pageview, klik, dan kedalaman scroll dikumpulkan otomatis. Untuk yang lain:

- **Goal pada elemen.** Tambahkan `data-revklik-goal="signup"` pada tombol atau
  tautan. Atribut `data-revklik-goal-*` tambahan menjadi properti goal, dan
  `data-revklik-goal-value="19"` melampirkan pendapatan.
- **Event kustom dari kode.** `klikapa.track("pricing_viewed", { plan: "growth" })`
  mencatat sebuah event, dan `klikapa.conversion("purchase", 19, { plan: "growth" })`
  mencatat konversi beserta pendapatannya.
- **Funnel.** Tandai bagian halaman dengan `data-section`; lihat
  [funnel](/id/dashboard/funnels).
- **Pengunjung yang dikenal.** `klikapa.identify({ ... })` menautkan data
  kontak ke seorang pengunjung. Panggil hanya dengan persetujuan pengunjung.

## 5. Persetujuan [#consent]

Secara bawaan tracker langsung berjalan begitu dimuat. Jika pengunjung Anda
mencakup penduduk Indonesia, UE, atau Inggris, minta persetujuan lebih dulu
dan mulai melacak hanya setelah pengunjung setuju:

```html
<script
	defer
	data-site-id="YOUR_SITE_ID"
	data-consent="required"
	src="https://app.revklik.com/klikapa.js"
></script>
```

```js
// saat pengunjung menyetujui banner Anda
klikapa.consent(true);

// saat pengunjung menolak atau mencabut persetujuan
klikapa.consent(false);
```

Sebelum `klikapa.consent(true)` dipanggil, tidak ada yang disimpan di browser
dan tidak ada yang dikirim. Persetujuan diingat, jadi pemuatan halaman
berikutnya berlanjut tanpa memanggilnya lagi. `klikapa.consent(false)` menghapus
ID pengunjung dan menghentikan pengiriman. Panduan lengkapnya ada di
[privasi dan persetujuan](/id/privacy).

## 6. Kecualikan perangkat Anda sendiri

Di dalam **Manage sites**, buka sebuah situs untuk melihat pengecualiannya:

- **Exclude this device**: menghentikan pelacakan pada browser yang Anda pakai
  untuk pengembangan (perangkat dikenali lewat hash berkunci dari IP, browser,
  dan bahasa). Lakukan sekali di setiap perangkat kerja Anda.
- **Purge my past visits**: menghapus event, sesi, dan profil pengunjung yang
  sudah tercatat untuk perangkat ini.
