Public API Documentation

Access RevKlik analytics data programmatically through the REST API. Authenticate with scoped tokens, rate-limited per plan, with standardized JSON responses.

Authentication & Base URL

Every request to the Public API must include an Authorization: Bearer header with a valid API token. Tokens start with the prefix rvt_ (account) or rv_ (site-scoped).

Base URL

https://app.revklik.com/api/v1

Example Request

curl https://app.revklik.com/api/v1/whoami \ -H "Authorization: Bearer rvt_your_token_here"
Token Prefix: The Public API only accepts rvt_ and rv_ tokens. kp_ session tokens only work in the internal dashboard.

Token Types

RevKlik offers two types of API token with different access levels:

PrefixTypeAccess
rvt_Account TokenAccess to all sites and features according to the granted scopes.
rv_Site TokenLimited to a single site. Default scopes: analytics:read, analytics:export.

Tokens are stored as SHA-256 hashes in the database. The full token is shown only once, when it is created.

Scopes & Permissions

Each token has a list of scopes that determines which endpoints it can access.

ScopeAccessDefault
sites:readList sites and view site detailsAccount
analytics:readQuery analytics dataAccount & Site
analytics:exportExport CSV/JSON dataAccount & Site
tokens:readList API tokensAccount
tokens:writeCreate & revoke tokensAccount

Rate Limits

Each API key has a per-minute rate limit based on your subscription plan.

PlanLimitMax Tokens
Free / Micro30 req/min2
Starter120 req/min5
Growth300 req/minUnlimited

Rate Limit Headers

Every response includes standard headers:

X-RateLimit-Limit: 120 X-RateLimit-Remaining: 87 X-RateLimit-Reset: 1715800000

When the limit is exceeded, the API returns 429 Too Many Requests.

Sites

GET /sites

List all sites. Account tokens see all sites; site tokens only see the site they are bound to.

sites:read

Response
[ { "id": "site_abc123", "name": "My Website", "domain": "mysite.com", "created_at": "2026-01-15T00:00:00Z" } ]

GET /sites/:siteId

Details of a single site by ID.

Analytics Endpoints

All analytics endpoints require the site_id and range parameters.

Parameters

ParameterTypeDescription
site_idstringID of the site to query. Required.
rangestringPeriod: 1h, 6h, 12h, 24h, 7d, 30d, 90d
limitnumberNumber of results (default 10, max 100). Optional.

analytics:read

Token Management

GET /tokens

List all API tokens (masked).

tokens:read

POST /tokens

Create a new API token.

tokens:write

Request Body
{ "name": "My CLI Token", "type": "account", "scopes": ["sites:read", "analytics:read"], "site_id": null }
Important: The full token is only shown in the response when it is created. It cannot be viewed again afterwards. Store it securely.
Response
{ "id": "tok_abc123", "token": "rvt_a1b2c3d4e5f6...", "prefix": "rvt_a1b", "name": "My CLI Token", "type": "account", "scopes": ["sites:read", "analytics:read"], "created_at": "2026-05-15T00:00:00Z" }

DELETE /tokens/:id

Revoke an API token. A revoked token stops working immediately.

tokens:write

SDK Examples

JavaScript / Node.js

const token = "rvt_your_token_here"; const base = "https://app.revklik.com/api/v1"; // Get analytics overview const res = await fetch( `${base}/analytics/overview?site_id=SITE_ID&range=7d`, { headers: { Authorization: `Bearer ${token}` } } ); const data = await res.json(); console.log(data.data);

Python

import requests TOKEN = "rvt_your_token_here" BASE = "https://app.revklik.com/api/v1" HEADERS = {"Authorization": f"Bearer {TOKEN}"} # List sites sites = requests.get(f"{BASE}/sites", headers=HEADERS).json() # Get analytics overview params = {"site_id": "SITE_ID", "range": "7d"} overview = requests.get( f"{BASE}/analytics/overview", params=params, headers=HEADERS ).json() print(overview["data"])

cURL

# Get timeseries data curl "https://app.revklik.com/api/v1/analytics/timeseries?site_id=SITE_ID&range=30d" \ -H "Authorization: Bearer rvt_your_token_here"
