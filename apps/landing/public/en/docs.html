Quick Start

Get analytics running in 2 minutes.

setup.html
1

Sign up in the dashboard

Create an account at app.revklik.com/register and get your unique Site ID.

2

Add the script tag

Copy this one line before </head> on all your HTML pages:

<script defer data-site-id="YOUR_SITE_ID"
  src="https://app.revklik.com/klikapa.js"></script>
3

Add section tracking (optional)

Add the data-section="name" attribute to each main section for scroll depth tracking:

<section data-section="hero">...</section>
<section data-section="pricing">...</section>
4

Show live numbers on your website (optional)

Turn it on under Settings → Live Widget in the dashboard, then paste this snippet before </body> to show online visitors, visitors today, and the total:

<script async data-widget-token="YOUR_WIDGET_TOKEN"
  src="https://app.revklik.com/klikapa-live.js"></script>
5

Done!

Data starts flowing within seconds. Open the dashboard to see real-time analytics.

Code examples for custom events and conversion tracking.

Custom Events

  plan: 'pro',
  method: 'google'
});

Conversion Tracking

  'purchase',
  49000,
  { product: 'Pro' }
);

Identify User

  email: 'user@mail.com',
  plan: 'growth'
