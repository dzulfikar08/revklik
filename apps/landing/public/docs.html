Quick Start

Aktifkan analytics dalam 2 menit.

setup.html
1

Daftar di dashboard

Buat akun di app.revklik.com/register dan dapatkan Site ID unik Anda.

2

Tambahkan script tag

Salin satu baris ini sebelum </head> di semua halaman HTML Anda:

<script defer data-site-id="YOUR_SITE_ID"
  src="https://app.revklik.com/klikapa.js"></script>
3

Tambahkan section tracking (opsional)

Tambahkan atribut data-section="name" ke setiap section utama untuk scroll depth tracking:

<section data-section="hero">...</section>
<section data-section="pricing">...</section>
4

Tampilkan angka live di website (opsional)

Aktifkan di Settings → Live Widget di dashboard, lalu tempel snippet ini sebelum </body> untuk menampilkan pengunjung online, pengunjung hari ini, dan total:

<script async data-widget-token="YOUR_WIDGET_TOKEN"
  src="https://app.revklik.com/klikapa-live.js"></script>
5

Selesai!

Data mulai mengalir dalam hitungan detik. Buka dashboard untuk melihat analytics real-time.
